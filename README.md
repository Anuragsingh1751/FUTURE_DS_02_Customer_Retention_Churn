## 📊 Project Overview

Customer retention and churn analysis project for **Future Interns — Data Science & Analytics Task 2**. The project analyzes 7,043 telecom customers to identify churn patterns, high-risk segments, and practical retention opportunities.

## 🔍 Key Business Insights

1. **Month-to-month contracts** have the highest churn rate at approximately **42.71%**.
2. **0–12 month customers** are a major retention opportunity, with the highest churn among tenure groups.
3. **Fiber optic** customers show higher churn than DSL customers.
4. Retained customers have a longer average tenure than churned customers.
5. The combination of **Month-to-month + 0–12 Months + Fiber optic** is a high-priority segment for retention action.

## 💡 Recommendations

- Strengthen onboarding and engagement during the first year.
- Encourage suitable month-to-month customers to move to longer contracts.
- Proactively support new Fiber optic customers.
- Build targeted retention campaigns using customer segments.
- Monitor churn-risk groups regularly and act before cancellation.
